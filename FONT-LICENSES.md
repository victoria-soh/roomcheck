# Font licences

RoomCheck bundles four font families, in the dashboard (`web/`, through `@fontsource` packages)
and in the PDF report (`app/report/data/`). All four are licensed under the SIL Open Font
License, Version 1.1. The full licence text for each is in `app/report/data/*-OFL.txt` and in
each `@fontsource` package's `LICENSE` file.

| Font | Copyright | Licence | Source |
|---|---|---|---|
| Plus Jakarta Sans | Copyright 2020 The Plus Jakarta Sans Project Authors | SIL OFL 1.1 ([text](app/report/data/plus-jakarta-sans-OFL.txt)) | https://github.com/tokotype/PlusJakartaSans |
| Atkinson Hyperlegible Next | Copyright 2020-2024 The Atkinson Hyperlegible Next Project Authors | SIL OFL 1.1 ([text](app/report/data/atkinson-hyperlegible-next-OFL.txt)) | https://github.com/googlefonts/atkinson-hyperlegible-next |
| JetBrains Mono | Copyright 2020 The JetBrains Mono Project Authors | SIL OFL 1.1 ([text](app/report/data/jetbrains-mono-OFL.txt)) | https://github.com/JetBrains/JetBrainsMono |
| Saira | Copyright 2020 The Saira Project Authors | SIL OFL 1.1 ([text](app/report/data/saira-OFL.txt)) | https://github.com/Omnibus-Type/Saira |

The fonts are used unmodified, as the `@fontsource` 5.3.0 builds (latin and latin-ext subsets).
