# RoomCheck docs

What's in this folder, and why each part matters.

| File or folder | What it is | Why it matters |
|---|---|---|
| [design-system.md](design-system.md) | Colours, type, spacing, components and the accessibility rules the dashboard follows, with how to regenerate the screenshots | The reference for building or changing any screen |
| [live-tests.md](live-tests.md) | Tests run on a real laptop and home network: setup, steps, expected results, what passed and when, and the recheck procedure | Evidence that RoomCheck works outside the mocked test suites |
| [bugs-from-live-tests.md](bugs-from-live-tests.md) | Bugs B1-B12 found in the live tests, each with its cause, fix and status | Shows what real use exposed and how each bug was fixed |
| [recheck-results.md](recheck-results.md) | The 6 Nov 2026 live recheck of those fixes, item by item, with masked log excerpts | Evidence that the fixes hold on a real network |
| [original-plan.md](original-plan.md) | The original design plan written at the start of the event | The intent behind each layer; where it differs, the README and the app are current |
| [screenshots/design-pass/](screenshots/design-pass/) | Every screen at 1280 and 390 px wide, plus the component gallery, from made-up demo data | See the app without running it |
| [branding/](branding/) | The RoomCheck mark and small icon, in colour, mono and on-dark versions (SVG) | The logo source; the app and the PDF use the same mark |

All addresses, MACs and network names in these files are masked or made up (192.0.2.x,
00:00:5E:00:53:xx, "Example-Home").
